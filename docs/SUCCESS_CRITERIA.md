# Rehearsal — Success Criteria (Definition of Done)

Use this checklist before calling the MVP complete.

## Auth & Onboarding
- [ ] User signs up via Google or magic link in under 30 seconds  
- [ ] 5-step onboarding completes with intent picker (solo vs team)  
- [ ] Org + membership created on first sign-in  

## Targets
- [ ] User builds target with 3+ sources  
- [ ] Synthesized personality profile shows source citations and confidence  
- [ ] Reconstruction polls status every 3 seconds on step 3  

## Documents
- [ ] User uploads PDF resume, sees embedding complete  
- [ ] Top 5 chunks retrieved at session creation  

## Scenarios
- [ ] All 10 conversation types configurable  
- [ ] Difficulty 1–5 produces different avatar behavior (via prompt modifiers)  
- [ ] Avatar brief preview works  

## Live Session
- [ ] Beyond Presence session starts with real video conversation  
- [ ] Pre-session consent required  
- [ ] Session ends, transcript syncs, evaluation runs, report within ~60 seconds  

## Reports
- [ ] Target-specific scores, moments, suggested answers use user context vocabulary  
- [ ] User rates accuracy (1–5 stars)  
- [ ] PDF export works  
- [ ] Zero forbidden phrases in evaluator output  

## Progress & Library
- [ ] Progress dashboard shows history + improvement chart  
- [ ] Library has 15 cloneable profiles (10 professional + 5 personal)  

## Team Mode
- [ ] Solo user sees **zero** team features (assignments, admin, company docs)  
- [ ] Team admin: invites, company docs, assignments  
- [ ] Team coach: pulse band on dashboard  

## Technical
- [ ] All pages mobile-responsive  
- [ ] Zero API keys exposed to browser  
- [ ] RLS verified: user A cannot read user B's org data  
- [ ] Deployed on Vercel with all env vars
